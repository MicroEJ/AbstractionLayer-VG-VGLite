# Overview

MicroEJ C Component: `com.microej.clibrary.llimpl#microvg-vglite`.

This component implements some Low-Level API (LLAPI) of MicroVG-1.x over VGLite library. 
Refer to the VEE Porting Guide > Vector Graphics > C Module to have more information on this module.

# VG Pack Compatibility

This compoment is MicroEJ VG Pack dependent: it is compatible with one or several MicroEJ VG Pack versions, listed in the [C Module compatibility](https://docs.microej.com/en/latest/VEEPortingGuide/vgReleaseNotes.html#c-modules-compatibility-version) tables in the documentation.

# Usage

Add the following line to your `module.ivy`:

    <dependency org="com.microej.clibrary.llimpl" name="microvg-vglite" rev="10.0.1"/>

2. Follow the **Usage** chapters of each component part (see VEE Porting Guide > Vector Graphics > C Module)
